# Mathematical Foundation

## 1. Overview

This document defines the mathematical representation used to formalize the Visual Question Answering (VQA) failure taxonomy developed for the Assamese Musical Instrument VQA system.

The purpose of this formulation is to represent each VQA prediction as a structured mathematical object so that subsequent failure categories can be defined through explicit decision functions rather than subjective inspection.

The overall formulation follows the mapping:

    VQA Sample
        ↓
    Model Inference
        ↓
    Prediction Tuple
        ↓
    Decision Functions
        ↓
    Failure Category

The mathematical representation established here serves as the foundation for the subsequent quantitative formulation and taxonomy algorithm.

---

## 2. Mathematical Notation

The following notation is used throughout the failure taxonomy.

| Symbol | Meaning |
|--------|---------|
| $\mathcal{I}$ | Image space |
| $I$ | Individual image |
| $\mathcal{Q}$ | Question space |
| $Q$ | Individual question |
| $\mathcal{G}$ | Ground-truth answer space |
| $G$ | Ground-truth answer |
| $\mathcal{P}$ | Prediction space |
| $P$ | Model prediction |
| $x$ | Individual VQA sample |
| $f_\theta$ | Trained VQA model |
| $\theta$ | Learned model parameters |
| $T$ | Complete prediction tuple |
| $\tau$ | Taxonomy classification function |
| $C$ | Resulting classification or failure category |

---

## 3. Image Space

Let $\mathcal{I}$ denote the space of valid input images.

An individual image is represented as:

$$
I \in \mathcal{I}
$$

For the present VQA task, $\mathcal{I}$ contains the images representing the seven Assamese musical instrument categories.

Conceptually:

$$
\mathcal{I}
=
\{I_1, I_2, \ldots, I_N\}
$$

where $N$ represents the number of images used in the corresponding dataset partition.

The image space provides the visual input to the VQA model.

---

## 4. Question Space

Let $\mathcal{Q}$ denote the space of questions used in the VQA dataset.

An individual question is represented as:

$$
Q \in \mathcal{Q}
$$

The question space contains the different question formulations associated with the semantic concepts evaluated in the dataset.

For example, questions may address:

- Festival
- Origin
- Material
- Parts
- Sound
- Traditional player
- Playing method
- Instrument type
- Description

Conceptually:

$$
\mathcal{Q}
=
\{Q_1, Q_2, \ldots, Q_M\}
$$

where each $Q_i$ represents a valid question instance.

---

## 5. Ground-Truth Answer Space

Let $\mathcal{G}$ denote the space of valid ground-truth answers.

An individual ground-truth answer is represented as:

$$
G \in \mathcal{G}
$$

The ground truth represents the expected answer associated with a particular image-question pair.

For example:

$$
Q = \text{"What material is this instrument made of?"}
$$

may have:

$$
G = \text{"This instrument is made of bamboo."}
$$

The ground truth is provided by the dataset and is independent of the model prediction.

---

## 6. Prediction Space

Let $\mathcal{P}$ denote the space of possible model-generated answers.

An individual prediction is represented as:

$$
P \in \mathcal{P}
$$

Unlike the ground-truth answer, $P$ is generated by the trained VQA model.

For example:

$$
P = \text{"This instrument is made of bamboo."}
$$

or, in an incorrect case:

$$
P = \text{"This instrument is made of wood."}
$$

Keeping $G$ and $P$ as separate mathematical objects is essential because the failure taxonomy evaluates the relationship between the expected answer and the generated answer.

---

## 7. Individual VQA Sample

A single VQA dataset sample is represented as:

$$
x = (I,Q,G)
$$

where:

- $I$ is the input image,
- $Q$ is the question,
- $G$ is the ground-truth answer.

Thus, a dataset can be represented as a collection of such samples:

$$
\mathcal{D}
=
\{x_i\}_{i=1}^{N}
$$

where:

$$
x_i = (I_i,Q_i,G_i)
$$

Each element of $\mathcal{D}$ therefore represents one image-question-ground-truth combination.

---

## 8. Model Inference

Let the trained VQA model be represented by:

$$
f_\theta
$$

where $\theta$ denotes the learned parameters of the model.

Given an image-question pair $(I,Q)$, the model generates a prediction:

$$
P = f_\theta(I,Q)
$$

Therefore:

$$
f_\theta :
\mathcal{I} \times \mathcal{Q}
\rightarrow
\mathcal{P}
$$

This defines the VQA inference process as a mapping from an image-question pair to a model-generated answer.

In words:

> The trained VQA model maps an input image and question to a predicted answer.

For the present work, $f_\theta$ corresponds to the fine-tuned Qwen2.5-VL model used for Assamese musical instrument VQA.

---

## 9. Complete Prediction Tuple

After model inference, the prediction can be combined with the original VQA sample.

The complete prediction tuple is defined as:

$$
T = (I,Q,G,P)
$$

where:

- $I$ = input image,
- $Q$ = question,
- $G$ = ground-truth answer,
- $P$ = model prediction.

Therefore:

$$
T
=
(I,Q,G,f_\theta(I,Q))
$$

This tuple contains all information required to analyze an individual model prediction.

---

## 10. Why the Prediction Tuple Is Required

The failure taxonomy must distinguish between several different aspects of a model response.

For example, the same predicted text can have different interpretations depending on:

- which image was provided,
- which question was asked,
- what the correct answer was,
- and what the model actually generated.

Therefore, evaluating the prediction using only $P$ is insufficient.

Instead, the complete evidence required for classification is represented by:

$$
T=(I,Q,G,P)
$$

This formulation allows subsequent decision functions to operate on a complete prediction instance.

---

## 11. Tuple Representation

A tuple preserves the role and ordering of its elements.

For example:

$$
T=(I,Q,G,P)
$$

is different from an arbitrary unordered collection of these elements because each position has a defined semantic meaning.

The first element represents the image, the second the question, the third the ground truth, and the fourth the model prediction.

This fixed structure allows the taxonomy to define functions directly over individual prediction instances.

---

## 12. From Prediction to Taxonomy

The mathematical representation becomes useful when the prediction tuple is passed to a taxonomy classification function.

Let:

$$
\tau
$$

denote the taxonomy function.

Then:

$$
\tau(T)=C
$$

where:

- $T$ is the complete prediction tuple,
- $\tau$ is the taxonomy classification function,
- $C$ is the resulting classification.

Thus:

$$
\tau :
\mathcal{T}
\rightarrow
\mathcal{C}
$$

where $\mathcal{T}$ represents the space of complete prediction tuples and $\mathcal{C}$ represents the set of defined prediction or failure categories.

The taxonomy is therefore formalized as a mapping from a prediction instance to a classification.

---

## 13. Correct and Failure Outcomes

The taxonomy may distinguish between a correct prediction and different forms of failure.

Conceptually:

$$
\tau(T)
\in
\mathcal{C}
$$

where $\mathcal{C}$ contains the categories defined by the proposed taxonomy.

For example, at the highest level:

$$
\mathcal{C}
=
\{
\text{Correct},
\text{Failure Categories}
\}
$$

The individual failure categories are formally defined in the subsequent methodology sections.

The important distinction is that the category is produced through a defined classification process rather than through an informal human statement such as "this answer looks wrong."

---

## 14. Relationship Between the Components

The complete mathematical pipeline can therefore be expressed as:

$$
(I,Q,G)
\rightarrow
f_\theta(I,Q)
\rightarrow
P
\rightarrow
T
\rightarrow
\tau(T)
$$

or equivalently:

$$
x=(I,Q,G)
$$

$$
P=f_\theta(I,Q)
$$

$$
T=(I,Q,G,P)
$$

$$
\tau(T)=C
$$

This sequence establishes the mathematical foundation for the failure taxonomy.

---

## 15. Dataset-Level Representation

For a dataset containing $N$ VQA samples:

$$
\mathcal{D}
=
\{x_i\}_{i=1}^{N}
$$

where:

$$
x_i=(I_i,Q_i,G_i)
$$

Model inference produces:

$$
P_i=f_\theta(I_i,Q_i)
$$

The corresponding prediction tuple is:

$$
T_i=(I_i,Q_i,G_i,P_i)
$$

The taxonomy function then assigns a category:

$$
C_i=\tau(T_i)
$$

Therefore, the complete dataset-level taxonomy output is:

$$
\mathcal{C}_{\mathcal{D}}
=
\{C_i\}_{i=1}^{N}
$$

This provides the basis for calculating category-level statistics in later stages of the methodology.

---

## 16. Formal Pipeline

The complete formulation can be summarized as:

$$
\boxed{
x_i=(I_i,Q_i,G_i)
}
$$

followed by model inference:

$$
\boxed{
P_i=f_\theta(I_i,Q_i)
}
$$

which produces the complete prediction tuple:

$$
\boxed{
T_i=(I_i,Q_i,G_i,P_i)
}
$$

and finally the taxonomy classification:

$$
\boxed{
C_i=\tau(T_i)
}
$$

Thus, the proposed framework can be summarized as:

    Dataset Sample
         |
         v
    x = (I, Q, G)
         |
         v
    Model Inference
         |
         v
    P = f_theta(I, Q)
         |
         v
    Prediction Tuple
         |
         v
    T = (I, Q, G, P)
         |
         v
    Taxonomy Function
         |
         v
    C = tau(T)

---

## 17. Scope of This Formulation

This mathematical foundation defines the objects required for the subsequent taxonomy formulation.

It does not, by itself, determine whether a prediction belongs to a particular failure category.

That decision requires additional functions and conditions describing:

- semantic properties of the question,
- relationships between the ground truth and prediction,
- attributes associated with the expected answer,
- conditions distinguishing different failure modes,
- and the precedence or decision rules used when multiple conditions may apply.

These components are defined in the subsequent methodology documents.

---

## 18. Summary

The proposed VQA failure-analysis framework begins by representing every prediction using four fundamental components:

$$
(I,Q,G,P)
$$

The model is represented as:

$$
P=f_\theta(I,Q)
$$

and the complete prediction is represented as:

$$
T=(I,Q,G,P)
$$

The taxonomy is subsequently expressed as a classification function:

$$
\tau(T)=C
$$

This formulation transforms an individual VQA prediction from an informal observation into a mathematically defined object that can be evaluated using explicit decision rules.

The resulting mathematical structure provides the foundation for the quantitative formulation and algorithmic definition of the proposed failure taxonomy.
